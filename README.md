# VK Video Live - Lag Monitor, Soft Reload & Max Quality

Tampermonkey-скрипт для [live.vkvideo.ru](https://live.vkvideo.ru), который показывает реальный лаг прямого эфира, позволяет одним кликом мягко ресинхронизироваться с лайвом и сам держит максимальное доступное качество видео.

## Возможности

- **Индикатор лага** — показывает текущее отставание от актуального лайва в секундах. Цвет точки: зелёный (< 5 с), жёлтый (5–15 с), красный (> 15 с). Значение берётся из внутреннего API плеера (`liveLatency$`), с фоллбэком на ручной расчёт через `video.seekable`, если API вдруг станет недоступен.
- **Мягкий перезапуск по клику** — клик по бейджу сбрасывает плеер к актуальному лайву (аналог нативной кнопки «Перемотать на лайв»), без перезагрузки страницы. Полезно при накопившемся лаге или зависшем видео.
- **Автоматическое максимальное качество** — раз в секунду проверяет текущее качество и, если оно не максимальное (например, плеер сам занизил его из-за авто-битрейта или после реконнекта), возвращает лучшее доступное разрешение — без открытия меню настроек и мигания UI.
- **Встроен в интерфейс, а не поверх него**:
  - когда чат открыт — бейдж вставлен прямо в шапку чата, рядом с остальными иконками;
  - когда чат свёрнут — всплывает над плеером в правом верхнем углу видео, под баннером алертов (если он есть у стримера), чтобы ничего не перекрывать;
  - синхронно скрывается/появляется вместе с остальными элементами управления плеера при бездействии курсора;
  - корректно работает и в полноэкранном режиме (в т.ч. с открытым чатом).

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. Откройте панель Tampermonkey → **Создать новый скрипт**.
3. Скопируйте содержимое [`vk-video-lag-monitor.user.js`](./vk-video-lag-monitor.user.js) целиком и вставьте вместо шаблона.
4. Сохраните (Ctrl+S). Скрипт автоматически включится на любой странице `live.vkvideo.ru/*`.

## Как это работает

Плеер VK Video написан на Svelte и хранит своё состояние в реактивном сторе (`document.querySelector('vk-video-player').store`), доступном прямо из консоли браузера. Скрипт использует его напрямую:

- `player.info.liveLatency$` — текущий лаг;
- `player.info.availableVideoTracks$` / `currentQuality$` — список качеств и текущее;
- `actions.setQuality(quality, false)` — принудительная установка качества;
- `actions.switchToActiveLive()` — ресинк к лайву (то же самое действие, что и нативная кнопка).

Если API плеера изменится в будущем (обновление сайта), скрипт откатывается на менее надёжные, но рабочие способы: поиск нужных элементов во вложенных shadow DOM плеера и клики по ним.

## Ограничения

- Завязан на внутренние CSS-классы и API конкретной версии плеера VK Video — при существенном обновлении сайта может потребоваться доработка.
- Автоматическое максимальное качество игнорирует ручной выбор пользователя в настройках плеера — если стрим лагает на слабом интернете, качество всё равно будет держаться на максимуме.
