# VK Video Live - Lag Monitor, Soft Reload & Max Quality

Tampermonkey-скрипт для [live.vkvideo.ru](https://live.vkvideo.ru), который показывает реальный лаг прямого эфира, позволяет одним кликом мягко ресинхронизироваться с лайвом и сам держит максимальное доступное качество видео.

## Возможности

- **Индикатор лага** — показывает текущее отставание от актуального лайва в секундах. Цвет точки: зелёный (≤ 5 с), жёлтый (5–60 с), красный (> 60 с, значение при этом показывается как «>60», без точного числа — выше минуты точность всё равно не нужна). Значение берётся из внутреннего API плеера (`liveLatency$`), с фоллбэком на ручной расчёт через `video.seekable`, если API вдруг станет недоступен или ещё не успело отдать значение (например, пока стрим только буферизуется).
- **Мягкий перезапуск по клику** — клик по бейджу сбрасывает плеер к актуальному лайву (аналог нативной кнопки «Перемотать на лайв»), без перезагрузки страницы. Полезно при накопившемся лаге или зависшем видео.
- **Автоматическое максимальное качество** — каждую секунду проверяет текущее качество и, если оно не максимальное (например, плеер сам занизил его из-за авто-битрейта или после реконнекта), возвращает лучшее доступное разрешение — без открытия меню настроек и мигания UI. Работает независимо от того, доступен ли в данный момент лаг.
- **Встроен в интерфейс, а не поверх него**:
  - когда чат открыт — бейдж вставлен прямо в шапку чата, рядом с остальными иконками;
  - когда чат свёрнут — всплывает над плеером в правом верхнем углу видео, под баннером алертов (если он есть у стримера), чтобы ничего не перекрывать;
  - синхронно скрывается/появляется вместе с остальными элементами управления плеера при бездействии курсора;
  - корректно работает и в полноэкранном режиме (в т.ч. с открытым чатом) — в fullscreen браузер рисует поверх всей страницы внутреннее поддерево плеера, поэтому там бейдж всегда уходит во floating-режим и переезжает внутрь fullscreen-элемента.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. Откройте панель Tampermonkey → **Создать новый скрипт**.
3. Скопируйте содержимое [`vk-video-lag-monitor.user.js`](./vk-video-lag-monitor.user.js) целиком и вставьте вместо шаблона.
4. Сохраните (Ctrl+S). Скрипт автоматически включится на любой странице `live.vkvideo.ru/*`.

## Как это работает

Плеер VK Video написан на Svelte и хранит своё состояние в реактивном сторе (`document.querySelector('vk-video-player').store`), доступном прямо из консоли браузера. Скрипт использует его напрямую:

- `player.info.liveLatency$` — текущий лаг;
- `player.info.availableVideoTracks$` / `currentQuality$` — список качеств и текущее;
- `actions.setQuality(quality, false)` — принудительная установка качества;
- `actions.switchToActiveLive()` — ресинк к лайву (то же самое действие, что и нативная кнопка).

Если API плеера изменится в будущем (обновление сайта), скрипт откатывается на менее надёжные, но рабочие способы: поиск нужных элементов во вложенных shadow DOM плеера и клики по ним.

## Ограничения

- Завязан на внутренние CSS-классы и API конкретной версии плеера VK Video — при существенном обновлении сайта может потребоваться доработка.
- Автоматическое максимальное качество игнорирует ручной выбор пользователя в настройках плеера — если стрим лагает на слабом интернете, качество всё равно будет держаться на максимуме.

## Changelog

- **5.5** — потолок адекватности лага снижен до 60 секунд: выше этого значение всё равно малочитаемо для человека, поэтому вместо точного числа показывается «>60», а индикатор становится красным (раньше красный включался при >15 с). Заодно это естественным образом решает проблему из 5.4 — даже если плеер на миг отдаст мусорное значение при ресинке, оно просто попадёт под тот же потолок.
- **5.4** — при частых кликах по бейджу (ресинк) плеер иногда на мгновение отдавал в `liveLatency$` мусорное значение (похоже на общее время стрима, тысячи секунд) - теперь такие нереалистичные значения отфильтровываются, а бейдж просто оставляет последнее нормальное число вместо вспышки неверного.
- **5.3** — исправлен краш в `updateLoop`: `liveLatency$.getValue()` иногда отдаёт `undefined` (а не `null`), пока стрим ещё буферизуется, и это ломало сразу и индикатор лага, и авто-выбор качества (он вызывался позже по коду и просто не успевал отработать из-за необработанного исключения). Теперь оба работают независимо друг от друга.
- **5.2** — floating-бейдж сдвинут ниже баннера алертов, если он есть у стримера.
- **5.1** — floating-бейдж синхронизирован со скрытием контролов плеера при бездействии курсора; исправлена работа в fullscreen (в т.ч. с открытым чатом).
- **5.0** — бейдж встраивается напрямую в DOM шапки чата вместо оверлея поверх плеера; клик по всему бейджу = мягкий reload.
- **4.0** и ранее — первые версии: оверлей с лагом поверх плеера, кнопка мягкого reload, авто-выбор максимального качества.
